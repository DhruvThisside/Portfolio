## Plan: Portfolio Website Design

- **Theme:** Modern dark theme with gradient accents (Purple to Blue gradient)
- **Style:** Clean, minimalist, professional yet trendy
- **Typography:** Modern sans-serif fonts (Poppins for headings, Inter for body)
- **Animations:** Smooth scroll, fade-in effects, hover animations

### Sections to Create
1. **Hero Section** - Name, title, tagline, social links, CTA button
2. **About Section** - Brief intro, photo placeholder
3. **Skills Section** - Categorized skills with visual badges/cards
4. **Projects Section** - Project cards with tech stack, links, descriptions
5. **Training Section** - Bootcamp details with capstone project
6. **Certificates Section** - Certificate cards with hover effects
7. **Achievements Section** - Hackathon rank, coding achievements
8. **Education Section** - Timeline format for education history
9. **Contact Section** - Email, phone, LinkedIn, GitHub links

1. `index.html` - Main HTML structure
2. `styles.css` - All styling with modern CSS
3. `script.js` - Animations and interactivity

### Design Features
- Responsive design (mobile, tablet, desktop)
- Glassmorphism effects on cards
- Gradient text and buttons
- Animated skill bars/badges
- Project cards with hover effects
- Smooth scroll navigation
